# 📖 اقرأني — طريقة التعديل السريعة

## الملف الرئيسي
كل الموقع في ملف واحد: **index.html**
- يتفتح بأي متصفح (دبل كليك) — مفيش تثبيت ولا أوامر مطلوبة.
- **كل التعديلات من مكان واحد:** افتح `index.html` ودوّر على كتلة **CONTENT** (حوالي سطر 256). فيها الأسماء وكلمة السر والرسائل والأغاني والفيديوهات والصور والتواريخ.

## مجلدات الميديا (جاهزة)
```
assets/
  music/    ← حط هنا الأغاني      (mp3 / m4a / ogg)
  images/   ← حط هنا الصور        (jpg / png / webp)
  videos/   ← حط هنا الفيديوهات   (mp4)
```
> استخدم أسماء إنجليزية للملفات (مثال: `song1.mp3`) عشان اللينكات تشتغل على كل الأجهزة.

## 1) إضافة أغنية 🎵
1. حط الملف في `assets/music`.
2. في كتلة CONTENT → `playlist` اكتب المسار:
```js
playlist: [
    "assets/music/song1.mp3",
    "assets/music/song2.mp3",
],
```
> أول ما تضيف أغنية، **زرار الموسيقى هيظهر تلقائياً** فوق شمال بعد الدخول. لو القائمة فاضية الزرار مخفي.

## 2) إضافة فيديو 🎥
- **فيديوهات قسم "فيديو حبنا":** حط الملفات في `assets/videos` واكتب مساراتها في `mainVideos` — كل فيديو بيظهر **بعرض الشاشة كامل** وطوله بيتظبط تلقائي على نسبة الفيديو نفسه (مش بيتقص) وبيتشغّل كامل:
```js
mainVideos: [
    "assets/videos/video1.mp4",
    "assets/videos/video2.mp4",
],
```
> كل فيديو تحت التاني على الموبايل والكمبيوتر. لو عايز تربطهم مشغل واحد فيه اختيار، قوللي وأنا أعملها. الفيديو بيشغّل بالصوت لما تدوس عليه، ولو عايز أكبر دوس علامة الشاشة الكاملة ⛶.
> لو `mainVideos` فاضية (مصفوفة فاضية)، القسم كله بيختفي (مش بيفضل مربع فاضي).

- **فيديو خلفية صفحة الدخول:** نفس الطريقة في `loginVideo`:
```js
loginVideo: "assets/videos/login-bg.mp4",
```

## 3) تعديل المحتوى ✏️ (كله من كتلة CONTENT)
| عايز تغيّر إيه | غيّر إيه |
|---|---|
| أسماء العروسين (إبراهيم ❤️ آية) | `names` |
| كلمة سر الدخول | `password` |
| مدة شاشة التحميل | `loadingDelayMs` (بالملي ثانية) |
| تاريخ العداد | `loveStartDate` + `counterDate` |
| الإشعارات اللي بتظهر كل شوية | `quotes` |
| الرسائل السريعة (زرار 💌) | `miniMessages` |
| ردود الشات العامة (الاحتياطية) | `botReplies` |
| مفاتيح الشات الذكي (كلمات → ردود) | دالة `smartReply` جوه مكوّن `BotChat` |
| الرسالة الكبيرة (الظرف ✉️) | `letter` |
| خط الذكريات + الصور | `timeline` |
| قسم "ليه بحبك" | `whyLove` |
| القصيدة | `poem` |
| الوعد | `promise` |
| رسالة الخاتمة (بتظهر واحدة واحدة في آخر الموقع) | `finalMessage` |

**لتغيير صور الذكريات لصوركم:** حط الصور في `assets/images` وغير `img`:
```js
{ t: "أحلى يوم", d: "الكلام هنا...", img: "assets/images/photo1.jpeg" },
```

## 3.6) الشات الذكي 💬
الشات بقى بيفهم الكلام وياخد باله من المعنى:
- **بحبك / بحبك أوي** → يرد حب وبيرد على قد الكلام (ولو كتبتي بحبك تاني بيقولك "أنتي كسبانة" 😄).
- **وحشتيني / مشتاقة** → رد شوق.
- **زعلانة / مخنوقة / تعبانة** → يطمنك ويقولك إنه ضهرك.
- **مين / ليه / ازاي / امتى / ؟** → يجاوبك بأسلوب حب.
- **جوعانة / أكل** → كلام أكل وحب.
- **تصبح على خير / نعسانة** → "تصبحي على خير".
- **اخبارك ايه / عاملة ايه** → يحكيلك يومه.
- **شكراً / تسلم** → رد لطيف.
- **ذكرى / جوازنا / خطوبتنا** → يحكي عن يوم 22/2/2026.
- أي كلام تاني → برد حب مفهوم ومرتب.

> كل الردود بتستخدم اسم **آية** تلقائي من `names`، والتاريخ من `counterDate`.

## 3.5) رسالة الخاتمة 🌙
بتظهر في آخر الموقع (زرار "الخاتمة ❤️✨") فقرة ورا فقرة كل حوالي 4 ثواني، وبعدها الأسماء. عدّلها من:
```js
finalMessage: {
    title: "💗✨🌙 حبيبتي ونجمة سمائي 🌙✨💗",
    paragraphs: [
        "الفقرة الأولى...",
        "الفقرة التانية...",
    ]
}
```

## 4) ليه الموقع بقى أسرع؟
- اتشالت مكتبة **Firebase** بالكامل (كانت بتتحمّل ومش مستخدمة أصلاً — وفرت حوالي 200KB).
- React بقى **نسخة الإنتاج** بدل نسخة التطوير (أخف وأسرع).
- شاشة التحميل اتقصّرت من 4.5 ثانية لـ 1.2 ثانية (قابلة للتعديل).
- الصور **Lazy Load** (بتحمّل لما توصلها بس) والفيديوهات `preload="none"`.
- اتشال كل الملفات المكررة والنسخ القديمة (كان فيه حوالي 20 نسخة مكررة).

## 5) تشغيل سريع للاختبار
أسهل طريقة: دبل كليك على `index.html`.
> ملحوظة: بعض المتصفحات بتمنع تشغيل الصوت لو الملف اتفتح مباشرة (file://). لو حصل ده، شغّل سيرفر بسيط:
```
python -m http.server 8777
```
وبعدين افتح: `http://localhost:8777/index.html`

## 6) قبل النشر
- جرّب الدخول بكلمة السر (`LOVE`).
- الميديا الحالية: أغنية `assets/music/08.Yana_Ya_Mafish.mp3`، ٧ صور في `assets/images` (photo1 → photo7)، وفيديوين في `assets/videos` (video1 و video2).
- افتح الموقع على الموبايل اتأكد إن كل حاجة شكلها كويس.
